# Workflow Change Proposal

---

## Bug Reference

- **Bug ID**: `20260430-003`
- **Bug Title**: z-index token 命名空间错误导致 @theme 定义无效

---

## Current Issue

### 问题描述

上一次修复（20260430-002）建立了 z-index token 体系，但由于 Tailwind v4 `@theme` 命名空间用错（`--z-*` 而非 `--z-index-*`），导致编译后 CSS 中**没有生成任何自定义工具类**，修复完全无效。

### 现有工作流缺陷

| 缺陷 | 说明 |
|------|------|
| **修复后无编译验证** | 修改 CSS/框架配置后，没有验证编译产物是否包含预期变更 |
| **框架 API 知识未文档化** | 项目中未记录 Tailwind v4 `@theme` 的关键命名空间映射规则 |
| **AI 生成代码未经验证** | AI 辅助生成的框架配置代码直接提交，未经编译验证 |
| **代码审查无法发现** | `--z-overlay: 30` 看起来合理，审查者无法肉眼判断 Tailwind 是否识别 |

## Proposed Change

### 1. 在 index.css 中文档化 @theme 命名空间规则

```css
/*
 * Tailwind v4 @theme 命名空间映射：
 *
 * CSS 属性       → @theme 前缀        → 工具类前缀
 * z-index       → --z-index-*        → z-*
 * color         → --color-*          → text-*, bg-*, border-*
 * font-family   → --font-*           → font-*
 * font-size     → --text-*           → text-*
 * font-weight   → --font-weight-*    → font-*
 * line-height   → --line-height-*    → leading-*
 * letter-spacing → --tracking-*      → tracking-*
 * border-radius → --radius-*         → rounded-*
 * box-shadow    → --shadow-*         → shadow-*
 * opacity       → --opacity-*        → opacity-*
 * transition    → --transition-*     → transition-*
 * animation     → --animate-*        → animate-*
 * spacing       → --spacing-*        → p-*, m-*, gap-*, etc.
 * container     → --container-*      → max-w-*
 * breakpoints   → --breakpoint-*     → sm:, md:, lg:, etc.
 */
```

### 2. 建立修复验证流程

在 CLAUDE.md 中添加修复验证要求：

```markdown
## Fix Verification Requirements

When modifying CSS, Tailwind configuration, or framework-specific code:
1. Run `pnpm build` after changes
2. Verify compiled artifacts contain expected changes
3. For CSS token changes, check that utility classes are generated correctly
4. Test in browser with DevTools to confirm computed styles
```

### 3. 添加构建后验证脚本

创建 `admin-frontend/scripts/verify-css-tokens.sh`，在 CI 或 pre-push hook 中运行。
